How It Works

1. Enroll: Record an identity reading the suggested phrase. The system extracts a 192-D biometric vector using CAM++.

2. Verify (1:N): Speak secretly. The API identifies who you are by computing cosine similarities against all enrolled profiles.

3. Verify (1:1): Select a specific identity from the dropdown to perform a 1:1 authentication check.

The pipeline runs completely on the CPU utilizing ONNX Runtime, making it lightning fast.
